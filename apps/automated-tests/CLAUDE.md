# Automated tests

This workspace contains CodeceptJS end-to-end coverage for the deployed storefront. It is the
only end-to-end engine. See `llm-wiki/tech/ADR/ADR-0003 CodeceptJS Is The End-To-End Test Engine.md`.

## Local structure

- Scenarios live in `codecept/**/*_test.ts`, page objects in `codecept/pages/`, and shared
  routes, fixtures and card data in `codecept/data/`.
- A page object default-exports a plain object and is registered by one entry in the
  `include` map in `codecept.conf.ts`. There is no fixture file to update. ESLint exempts
  `codecept/**` from `import/no-default-export` for this reason.
- `steps.d.ts` is generated by `pnpm test:e2e:def`. Regenerate it after changing a page
  object and never hand-edit it. The generator emits single quotes and leaves the support
  interface on one line; `.prettierignore` lists the file, so `format:check` does not cover
  it and `pnpm format` will not rewrite it. Commit the generator's output as it comes.
- `TEST_ENV_URL` is required and `codecept.conf.ts` throws without it. `LOCALE` selects the
  URL prefix through `codecept/data/locales.ts`: `us` gives no prefix, `gb` gives `/gb`, the
  default is `us`, and any other value throws. `LOCALE` also picks the address fixture, so a
  silent fallback would pair one country's URLs with another's address data. Credentials come
  from `USER_EMAIL` and `USER_PASSWORD`. Never hardcode live credentials or production URLs.
- `playwright` is a dependency because `helpers.Playwright` drives the browser. It is pinned
  to an exact `1.59.1` and is referenced only by the helper name, so a dead-code sweep will
  report it as unused. Do not remove it.
- Chromium only, and no retries. A single flake fails the run, so keep scenarios independent
  and prefer `I.waitInUrl` or `I.waitForText` with an explicit timeout over a bare assertion.
  Wait timeouts are in **seconds**, not milliseconds.
- A failed scenario writes one screenshot to `output/`. There is no trace, video, or HTML
  report.
- `homepage` and `homepagePage` are a known duplicate pair of homepage page objects. Extend
  one of them rather than adding a third.

## Commands

- Full suite: `pnpm test:e2e`
- One scenario file: `pnpm exec codeceptjs run codecept/<name>_test.ts --steps`
- Regenerate types: `pnpm test:e2e:def`
